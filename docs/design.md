# Visual direction

The interface is a research observatory: an expansive network diagram leads, a compact instrument panel changes its conditions, and an evidence drawer exposes decisions. Left-aligned hierarchy, generous space around the network, dense but readable details underneath.

Palette: deep ocean #101e32, slate #263c55, cloud #edf3f8, ice #a9d9f5, apricot #ffb78d, violet #b9aff0. Ice represents participants and evidence; apricot marks risk and challenges; violet marks provisional work. Status is also written, never color alone.

System typography: Avenir Next with sans-serif fallbacks for interface and a serif display title suggesting an institution rather than a trading terminal. No remote fonts or other external assets.

The network is the single expressive element. Motion shows evidence moving through actual pipeline stages and stops when paused or reduced motion is requested. Other surfaces remain quiet.

Review against brief: avoid a finance-dashboard reward hero. Lead with the question-to-evidence-to-check process; reward totals sit beside failures and capacity limits. Mobile changes the pipeline to a vertically scrollable section while keeping every control and claim available.
